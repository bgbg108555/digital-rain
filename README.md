# Digital Rain

A hacker-terminal look for the Claude desktop app: phosphor-green colors, falling code rain behind the conversation, and a live readout above the prompt that races while Claude works.

- **Colors**: green-on-black terminal palette in dark mode, green-bar printout paper in light mode.
- **Backdrop**: three depth layers of sparse code rain with long fading tails and white heads, behind frosted panels. While a turn runs the rain speeds up and a small PROCESSING tag appears.
- **Band above the prompt**: link status, a scrolling hex ticker, a spectrum, a load meter and a scrambling address. It reads `LINK:SECURE` when idle and `DECRYPTING`, faster, while Claude works.
- **Working row**: a scrambling hex strip with a scanner in place of the usual spinner.

Everything holds still when your system asks for reduced motion. Some desktop setups still the backdrop's animation; the rain then rests in a laid-out still frame, and the band and the working row keep moving.

## Install

At the prompt of a terminal session:

```
/plugin install digital-rain --marketplace bgbg108555/digital-rain
```

Answer `y` to add the marketplace, then pick a scope (user scope puts it in every session).

From a shell:

```
claude plugin install digital-rain --marketplace bgbg108555/digital-rain
```

In the desktop app, where `/plugin` does not run: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `bgbg108555/digital-rain`, then **Add plugin**.

The look draws in the desktop and mobile apps; the terminal keeps its own.

## Changing the scenes

The backdrop, the band and the working row are SVG generated by `scripts/gen-scene.mjs`. Edit it, then rebuild:

```
node scripts/gen-scene.mjs hooks/scene.js
```

The colors are the `makeColors` call in `hooks/register.tsx`.
